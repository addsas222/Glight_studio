# 凌日光影棚 —— 中文用户手册

**版本 1.0 ｜ 适用：独立桌面软件（Windows / macOS / Linux）**

凌日光影棚为「加查俱乐部」及同类 2D 动漫风格的**图片与视频**重新打光：
先用 AI 估计画面深度与法线，再用本地物理渲染引擎做多光源光照，
最后导出**同尺寸的图片新文件**或**同格式的视频新文件**。
**原图/原片内容永不被重绘，只改变光照。**

软件**不依赖任何图像编辑软件**（GIMP/Photoshop 等），导入、分析、调光、
导出全部在软件内完成。

> 视频操作的完整说明见 **[视频处理操作指南](./视频处理指南.md)**；
> 本手册第 11 节给出要点与入口。

## 1. 安装与启动

### 1.1 Windows（.exe）

1. 双击 `HorizonLightStudio.exe` 即可运行（绿色版，无需安装 Python）。
2. 若使用安装包版本，双击 `HorizonLightStudio-1.0.0-Setup.exe`，
   按向导完成安装后在开始菜单启动「凌日光影棚」。

> 首次运行会创建用户目录 `%USERPROFILE%\.horizon_light_studio\`，
> 用于存放设置、模型与缓存。

### 1.2 macOS（.dmg）

1. 打开 `凌日光影棚-1.0.0.dmg`；
2. 把「凌日光影棚」拖入「应用程序」；
3. 首次打开若提示「无法验证开发者」（未签名分发时的正常现象），
   在「系统设置 → 隐私与安全性」中点击「仍要打开」，
   或执行 `xattr -dr com.apple.quarantine "/Applications/凌日光影棚.app"`。

### 1.3 Linux（.AppImage）

```bash
chmod +x 凌日光影棚-1.0.0-x86_64.AppImage
./凌日光影棚-1.0.0-x86_64.AppImage
```

若系统缺少 FUSE：
`./凌日光影棚-1.0.0-x86_64.AppImage --appimage-extract-and-run`

### 1.4 从源码运行（开发者）

```bash
pip install -r requirements.txt      # 引擎 + WebUI 运行依赖（无需 Qt）
python -m webui.desktop              # 启动本地服务并自动打开界面
```

> 软件共 **13 个界面**：光影工作台、智能打光、专业模式、视频调光、逐帧光绘、
> 光源星图、智能拾光、三维布光预演、暗房终端、调光台、光影指挥屏、插件中心、主题引擎。

## 3. AI 深度后端

软件按**四级链**依次尝试获取深度，任一级失败或超时（默认 3 秒）自动降级到
下一级，**界面永不阻塞**（渲染在后台线程执行）。

| 优先级 | 后端 | 联网 | 说明 |
|---|---|---|---|
| ① | 内置本地引擎 | 否 | ONNX 深度 + 可选法线，质量最好，推荐 |
| ② | 自建服务 | 否 | 你自己部署的 FastAPI 服务（见第 4 节） |
| ③ | 云端 API | **是** | 阿里云 / Replicate / OpenAI 兼容 |
| ④ | 灰度模拟 | 否 | 保底「仅预览模式」，无模型时保证可用 |

默认顺序为 `builtin → local → cloud → simulate`，可在
**设置 → AI 后端设置**中逐项启用/禁用。

### 3.1 内置模型

菜单 **设置 → AI 后端设置**，点「**一键下载模型**」，按需选类型：

| 模型 | 体积 | 作用 | 是否必需 |
|---|---|---|---|
| Depth Anything V2 Small | 约 94MB | 深度图（ControlNet 深度预处理同源，效果最好） | 深度模型二选一 |
| MiDaS-small | 约 64MB | 深度图（体积更小，老机器更友好） | 深度模型二选一 |
| MoGe-2 法线 | 约 134MB | 法线图（真实表面法线，光照更立体） | 可选 |

- 深度模型**装任意一个即可**；两个都装了会**自动优先用 Depth Anything V2**，
  不需要手动切换（按 ONNX 文件内部签名识别，改文件名不影响）。
- 法线模型可选。**不装也能正常用** —— 软件会用深度图几何派生法线，
  只是曲面细节略少。
- 无网环境：在别处下载 `.onnx` 后用「**离线导入模型…**」选择文件即可。
  界面按**深度 / 法线**分类导入，选错类型会明确提示，不会导入成功却用不了。

> **国内网络提示**： huggingface.co / github.com 常常连不上（下载会超时）。
> 三种办法任选：
> ① 换镜像地址覆盖下载源（默认已指向 `hf-mirror.com`）：
> `set HLS_DEPTH_MODEL_URL=https://<你的镜像>/model.onnx`
> （法线用 `HLS_NORMAL_MODEL_URL`，MiDaS 用 `HLS_MODEL_URL`；
> Linux/macOS 用 `export`）；
> ② 手动把 .onnx 放入 `~/.horizon_light_studio/models/`
> （深度文件名：`depth-anything-v2-small.onnx` 或 `model-small.onnx`；
> 法线文件名：`moge2-vits-normal.onnx`），软件检测到就**不会重复下载**；
> ③ 用界面里的「离线导入模型…」指定任意位置的 .onnx。

模型默认存放于 `~/.horizon_light_studio/models/`。
**软件本身不捆绑任何模型权重。**

### 3.2 设置会被保存

所有 AI 后端设置（启用开关、自建服务地址、云端密钥与模型、超时、
仅预览模式）保存在 `~/.horizon_light_studio/config.json`，下次启动自动恢复。
密钥仅存本机，只在使用云端后端时才会联网。

## 4. 自建本地深度服务（部署教程）

适合希望得到更好深度质量、又不想用云端的用户。服务是**独立进程**，
软件通过 HTTP 调用 `http://127.0.0.1:8765`。

> **前提**：本地服务与内置引擎是两种不同的深度来源。若你把内置引擎
> 保持启用，链会在内置引擎处就命中，**自建服务不会被调用**。要使用自建
> 服务，请在「设置 → AI 后端」中**取消勾选「启用① 内置本地深度引擎」**。

### 4.1 一键部署

**Windows**

```bat
cd server
setup_deployment.bat
```

**Linux / macOS**

```bash
cd server
chmod +x setup_deployment.sh run_server.sh
./setup_deployment.sh
```

部署脚本会：创建**服务专用虚拟环境 `.venv-server`**（与开发用的 `.venv` 分开）
→ 安装 `server/requirements.txt`
（fastapi / uvicorn / onnxruntime / pillow / numpy）→ 下载深度模型
（优先 Depth Anything V2 Small，约 94MB）。

### 4.2 启动服务

**Windows**

```bat
cd server
run_server.bat
```

**Linux / macOS**

```bash
cd server
./run_server.sh
```

**或手动启动（任意平台）**

```bash
source .venv-server/bin/activate   # Windows: .venv-server\Scripts\activate.bat
uvicorn server.app:app --host 127.0.0.1 --port 8765
```

启动成功后：

- 服务地址：`http://127.0.0.1:8765`
- 健康检查：浏览器打开 `http://127.0.0.1:8765/health`
  正常时返回 `{"status":"ok","ready":true,...}`
- 交互式接口文档（FastAPI 自带）：`http://127.0.0.1:8765/docs`

### 4.3 在软件中启用

**设置 → AI 后端设置** → 勾选「启用② 用户自建 FastAPI 服务」，
地址填 `http://127.0.0.1:8765` → 确定。

### 4.4 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `HLS_MODEL_PATH` | 自动挑选：已部署的 `depth-anything-v2-small.onnx`，否则 `model-small.onnx` | 深度 ONNX 模型路径 |
| `HLS_NORMAL_MODEL_PATH` | `~/.horizon_light_studio/models/moge2-vits-normal.onnx`（存在时） | **法线** ONNX 模型路径；文件不存在则由深度几何派生法线 |
| `HLS_MODEL_URL` | GitHub Releases 地址 | 覆盖 **MiDaS** 模型的下载源（国内可指向镜像；已存在的模型不会重复下载） |
| `HLS_DEPTH_MODEL_URL` | `hf-mirror.com` 镜像地址 | 覆盖 **Depth Anything V2** 的下载源 |
| `HLS_NORMAL_MODEL_URL` | `hf-mirror.com` 镜像地址 | 覆盖 **MoGe-2 法线**模型的下载源 |

> 服务端不按文件名硬编码模型：**MiDaS 与 Depth Anything V2 都支持**，
> 按 ONNX 文件内部签名自动识别，用户换文件即可换引擎。

### 4.5 排障

| 现象 | 原因与处理 |
|---|---|
| `/health` 返回 `"ready": false` | 模型未就绪。运行 `setup_deployment` 下载，或设 `HLS_MODEL_PATH` 指向已有 .onnx 后**重启服务** |
| 接口返回 **503** | 同上：模型未加载。服务**不会伪造深度**，桌面软件会如实降级到「仅预览」或云端 |
| 接口返回 **413** | 图片尺寸超出范围（短边 < 64 或长边 > 4096） |
| 接口返回 **400** | 请求体为空或不是可解析的图片 |
| 软件状态栏显示「仅预览（灰度模拟）」 | 自建服务未启动或模型未就绪；确认服务在跑且 `ready: true` |
| 端口 8765 被占用 | 换端口启动（如 `--port 8899`），并在软件设置中同步修改地址 |

## 5. 云端 AI 后端

联网时可用，适合高分辨率图片。

**设置 → AI 后端设置** → 勾选「启用③ 云端 API」，选择提供商：

| 提供商 | Base URL 示例 | 模型 / Action |
|---|---|---|
| OpenAI 兼容通用 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-vl-max` |
| Replicate | `https://api.replicate.com/v1` | model version hash |
| 阿里云视觉智能 | 能力 endpoint URL | Action 名，如 `EstimateImageDepth` |

> **高分辨率提示**：当图片长边超过 **1600px** 且云端未启用时，软件会弹出
> 对话框询问是否启用云端 API（每张图片只询问一次）。开启后能获得更准确
> 的深度与法线。

**超时与降级**：云端各级超时（默认 3 秒，可调）会自动跳过并降级到
下一后端，界面不会卡死。

## 6. 光源与光照调节

### 6.1 无限多光源

- 「**＋ 添加光源**」可任意数量添加，无上限；
- 光源列表中选中某光源，即可在下方属性面板编辑；
- 「**删除此光源**」移除当前光源（至少保留一个）。

### 6.2 每个光源的参数

| 控件 | 范围 | 说明 |
|---|---|---|
| 光源名称 | 任意文本 | 便于识别多光源场景 |
| 光源类型 | `directional` / `point` | 方向光=平行光（日光/月光）；点光=画面内某点发光（舞台灯/霓虹） |
| **方向（3D 轨迹球）** | 拖拽 | 黄色手柄在球面上的位置即光线方向；圆盘下方实时显示 `dx/dy/dz` |
| **强度** | 0~4 | 滑块 |
| **色温** | 1500~12000K | 滑块，实时显示 K 值（低=暖橙，高=冷蓝） |
| **半径** | 0.05~1.5 | 点光的距离衰减范围 / 柔化半影的模糊尺度 |
| 点光 X / Y / 高度 Z | 0~1 / 0.05~3 | 仅 `point` 类型使用 |
| 启用此光源 | 勾选 | 临时关闭而不删除 |

## 7. 双路径智能拾取

两条路径**都已实现**，可单独使用或组合。

### a. 点击映射（像素 → 光源方向）

1. 点「**◎ 点击图片拾取主光**」进入拾取模式；
2. 在画布中点击一个像素（建议点角色脸颊、衣服等受光面）；
3. 主光源立刻锚定为**该点法线的逆方向**——软件取该像素 7×7 邻域的
   平均法线做抗噪，再反转方向，得到自然的立体受光；
4. 状态栏显示新方向值；拾取模式自动退出，并立即刷新预览。

> 需要点击前先等深度就绪；若深度尚未算出，软件会提示稍候。

### b. 保守参考图迁移

1. 准备一张「光照氛围好看」的参考图（任意 PNG/JPEG）；
2. 菜单 **文件 → 导入参考图（保守迁移）**；
3. 软件提取参考图的**主光方向**（亮度梯度）与**全局色温**（R/B 比），
   作为**偏移量**叠加到当前参数：

   - 方向最多偏转 **±15°**
   - 色温最多 **±500K**
   - 强度最多 **±0.25**

   **限幅**保证原图固有明暗结构被保留，只做柔和微调，绝不暴力重绘。

4. 迁移完成后可点「**撤销参考图迁移**」一键还原到迁移前的参数。

## 8. 阴影锐度、环境光与性能模式

### 8.1 阴影锐度（一键切换）

| 选项 | 效果 |
|---|---|
| **硬朗（日系赛璐珞风）** | 阴影边缘锐利二值化，动漫赛璐珞质感 |
| **柔化半影（摄影棚风）** | 阴影边缘柔和过渡（按光源半径模糊），摄影棚质感 |

### 8.2 环境光（独立调节）

- **环境光强度** 0~2、**环境光色温** 2000~12000K，与所有光源相互独立，
  控制画面整体底光。
- **整体曝光** 0.2~2.5，控制最终输出亮度。

### 8.3 性能模式

| 模式 | 光照算法 | 1024px 实测 | 用途 |
|---|---|---|---|
| **快速预览（线性叠加）** | 逐光源线性叠加，不做阴影投射 | 约 0.2s | 调参时实时反馈 |
| **高质量（物理阴影）** | 2.5D 高度场逐光源阴影投射，支持**多光源互斥遮挡**；按 `lighting_size`（默认 1024）计算光照后上采样到原尺寸 | 约 2.2s | **最终出图** |

> 无论哪种模式，**输出始终是原图尺寸**（代理分辨率只影响光照计算开销）。

## 9. 预设场景与一键重置

**5 种预设场景**（下拉框切换，切换后可在其基础上继续手工微调）：

| 预设 | 特征 |
|---|---|
| **标准棚拍** | 柔光箱主光 + 轮廓补光，中性白平衡 |
| **逆光黄昏** | 暖色夕阳逆光 + 冷天光补光，低环境光 |
| **冷色月夜** | 高色温月光 + 地面反光，硬阴影 |
| **舞台聚光** | 顶部聚光 + 左右染色灯，硬阴影、强高光 |
| **霓虹氛围** | 左粉右青双色霓虹 + 顶部白光 |

**一键重置**：光源面板上方「**↺ 重置全部参数**」按钮，把当前预设的
**所有**参数恢复默认——包括光源列表与其全部属性、环境光强度/色温、
整体曝光、阴影锐度、性能模式，并清除参考图迁移偏移。

## 10. 输入输出、缓存与离线说明

### 10.1 输入

- 图片：**PNG / JPEG**，尺寸 **64 ~ 4096 px**（宽与高都需在此范围；超出会明确报错）
- 视频：**MP4 / AVI / MOV**（另支持 MKV / M4V / WEBM），建议 ≤1080p、≤5 分钟
  （详见第 11 节）
- 透明背景自动合成到白底（动漫立绘常见）

### 10.2 输出

- 图片：菜单 **文件 → 导出结果**，在保存对话框中**自定义路径、文件名与格式**
  （PNG 或 JPEG）；输出永远是**与输入同尺寸**的**新文件**，原图不受影响。
- 视频：菜单 **文件 → 导出视频**，输出**同格式**视频
  （分辨率/帧率/帧数与源一致，**保留原音轨**），原视频不受影响。

### 10.3 缓存

AI 分析结果按**内容哈希 + 后端标识**缓存于
`~/.horizon_light_studio/cache/<key>/`：

- `meta.json` —— 元数据（后端、尺寸、写盘时间）
- `depth.png` —— 深度图
- `normal.png` —— 法线图（若该后端提供了法线）

**同一张图片不会重复调用 AI**（状态栏显示「缓存命中」）。
视频同理：**同一段视频的同一关键帧/同一帧不会重复分析**。
设置面板中可「清理缓存」。

> 视频的临时工作文件位于 `~/.horizon_light_studio/video/`，
> 软件启动时会自动清理残留文件。

### 10.4 网络依赖

| 功能 | 是否需要联网 |
|---|---|
| 内置本地引擎 | 否（仅首次下载模型需联网，可离线导入） |
| 自建本地服务 | 否 |
| 仅预览模式（灰度模拟） | 否 |
| 云端 API | **是** |

**只有一个 AI 后端需要联网。** 断开网络时，软件仍可完整完成
导入 → 分析 → 调光 → 导出，只是深度质量降为灰度模拟。

## 11. 视频处理

> 完整操作说明（模式选择、预览与逐帧检查、耗时估算、排障）见
> **[视频处理操作指南](./视频处理指南.md)**。本节为要点。

### 11.1 支持范围

| 项 | 说明 |
|---|---|
| 输入格式 | **MP4 / AVI / MOV**（另支持 MKV / M4V / WEBM） |
| 建议 | 分辨率 ≤1080p、时长 ≤5 分钟 |
| 硬性上限 | 长边 ≤4096、时长 ≤30 分钟（超出会明确拒绝） |
| 输出 | **同格式视频**，同分辨率/帧率/帧数，**保留原音轨** |

### 11.2 两种处理模式

| 模式 | 做法 | 光照 | 速度 | 适合 |
|---|---|---|---|---|
| **关键帧分析传播**（默认） | 仅对关键帧做 AI 分析，其余帧深度在相邻关键帧间线性插值 + 时间轴平滑 | 全片统一 | 快（AI 次数 = 关键帧数） | 加查动画、镜头变化不剧烈 |
| **逐帧分析**（高质量） | 每帧单独 AI 分析 | 随画面动态变化 | 慢（与帧数成正比） | 镜头运动明显、遮挡复杂 |

### 11.3 操作要点

1. 顶栏「**打开视频**」导入文件，软件显示分辨率/帧率/时长/帧数/音轨；
2. 选择处理模式与关键帧数量；
3. 光照调节与图片**完全相同**（预设、光源、轨迹球、环境光，见第 6–9 节）；
4. 可**播放预览**、**逐帧步进检查**，并在任意一帧上用「拾取主光」
   点击像素锚定该点法线的逆方向；
5. 「开始处理」在后台执行，可随时取消（会清理半成品文件）；
6. 完成后「导出视频」保存到自定义路径。

> 分辨率超过 1080p 或时长超过 5 分钟时，软件会提示建议启用云端 AI 后端。

### 11.4 性能（实测）

| 场景 | 实测 | 规格上限 |
|---|---|---|
| 1920×1080 · 30fps · 10s（300 帧，关键帧传播） | **≈ 96.7s** | **≤ 5 分钟** |
| 逐帧分析 | 随帧数线性增加 | — |

视频处理内存平稳（1080p 全片约 +122MB）：深度按帧流式生成。

## 12. AI 自动打光（文字 → 光照节点）

用一句中文描述灯光，软件直接**生成可编辑的光照节点**，不需要手动摆灯。

### 12.1 用法

1. 左侧「**光照描述（自然语言）**」输入框写下想要的灯光，例如：
   > 黄昏时分的舞台逆光，暖橘色主光从左后方打来，冷蓝补光勾勒人物轮廓，空气中有薄雾感
2. 点「**生成光照节点**」；
3. 右侧「光源属性」立即出现生成的光源节点，可继续拖轨迹球、调滑块微调；
4. 结果下方的**解析说明**会回显解析结论，例如
   `舞台聚光 · 解析：主光 左后 · 暖色 3000K · 补光+轮廓光`。

### 12.2 解析规则（离线、确定性）

| 描述里的词 | 效果 |
|---|---|
| 舞台 / 聚光 / 演唱会 | 基调取「舞台聚光」 |
| 霓虹 / 赛博 / 夜市 | 基调取「霓虹氛围」 |
| 月夜 / 夜晚 / 月光 | 基调取「冷色月夜」 |
| 黄昏 / 夕阳 / 逆光 / 落日 | 基调取「逆光黄昏」 |
| 棚拍 / 影棚 / 柔光箱 / 标准 | 基调取「标准棚拍」 |
| 左 / 右 / 顶部 / 上方 / 地面 / 下方 | 决定光的方向 |
| 逆光 / 背后 / 背光 | 光源移到主体后方（降低朝向观察者的分量） |
| 暖 / 橘 / 金 / 烛 | 色温约 3000K |
| 冷 / 蓝 / 青 / 月 | 色温约 9200K |
| 白 / 中性 / 日光 | 色温约 5600K |
| 直接写 `4300K` | 以显式数值为准 |
| 强 / 亮 / 刺眼 | 提高强度；舞台/硬光 → 硬朗阴影 |
| 柔 / 弱 / 淡淡 | 降低强度；默认柔化半影 |
| 轮廓 / 边缘光 | 追加一盏轮廓光 |
| 补光 / 填充 | 追加一盏补光 |

**这一步完全离线**：不需要联网、不需要模型权重，同样的描述永远得到同样的结果。

### 12.3 云端增强（可选）

在「设置 → AI 后端」启用云端并填好密钥后，自动打光会**额外**尝试用大模型做更
细致的解析；成功则采用云端结果（解析说明会标注「云端解析」），
**失败/超时/无密钥时自动回落到离线结果**，不会卡住界面。

> 输出即为标准光源节点，可直接进入第 13 节的「专业模式」工作流继续编排。

## 13. 专业模式（工作流节点图）

面向需要精确控制与可复用流程的用户：把光照拆成**节点**连线，形成可保存、
可重放的工作流。

### 13.1 可用节点

| 节点 | 作用 |
|---|---|
| **输入** | 图片或视频素材进图 |
| **AI 深度** | 调用 AI 预处理层获取深度/法线 |
| **AI 自动打光** | 由文字描述生成光源（见第 12 节） |
| **光源** | 添加一盏可调光源 |
| **全局光照** | 设置环境光强度/色温、曝光、阴影锐度、性能模式 |
| **点击拾取** | 用点击像素的方式锚定主光方向 |
| **参考图迁移** | 以参考图的方向/色温做保守偏移 |
| **输出** | 交付渲染结果 |

### 13.2 求值规则

- 节点按**拓扑顺序**求值；同一层按书写顺序，结果稳定可复现。
- **光源节点是累加**的：多个光源节点叠加成多光源场景（顺序不影响结果）。
- 数值会按引擎范围**自动限幅**（强度 0~4、色温 1500~12000K、半径 0.05~1.5、
  曝光 0.2~2.5 等），写超范围不会崩，只会被夹到合法值。
- **存在环路或未知节点类型时会明确报错并拒绝求值**，不会静默给出错误结果。
- 工作流可导出/导入 JSON，便于保存常用打光流程或团队共享。

## 14. 插件管理与扩展

「插件管理」提供统一的**可拓展入口**，用于扩展预设、主题、灯组与后端。

- 插件是**纯数据（JSON 清单）**：软件只解析数据，**永不执行插件代码**，
  因此安装第三方插件不会带来执行任意代码的风险。
- 支持的类型：`preset`（预设场景）、`theme`（界面配色）、
  `light-rig`（成套灯组）、`backend`（后端声明）。
- 每个插件可**单独启用/停用**，状态持久保存在
  `~/.horizon_light_studio/plugins/state.json`；停用后其贡献立即失效。
- 清单字段非法、未知名、损坏的 JSON 都会被**明确拒绝或跳过**，不会让软件崩溃。

仓库自带可参考的示例插件（`plugins/examples/`）：暖色灯组、预设、
以及一套主题，可作为编写插件的模板。

## 15. 主题引擎（界面配色）

- 默认配色为**蓝色（暗夜蓝调）**，与产品视觉一致；
- 顶栏「主题」下拉可切换 **8 套主题**：

## 17. 逐帧光绘（视频逐帧画笔）

在视频上**逐帧手绘光效**，与光照渲染叠加后导出新视频。

- **光笔类型**：点光源（锐利高聚集）/ 柔光晕（柔和扩散）/ 光束（定向锥形）/
  星芒（十字衍射）；
- **笔刷参数**：强度、半径、色温、柔边；光束可调张角，星芒可调条数；
  **混合模式**：叠加（add）/ 滤色（screen）/ 柔光（soft）；
- **画法**：在画面上按下并拖动即可绘制；拖动方向决定光束朝向；
- **洋葱皮**：显示相邻帧的笔迹，便于逐帧对齐；
- **图层**：每种笔刷类型是一个图层，可单独隐藏（隐藏后预览与导出同时生效）；
- **时间轴**：缩略图 + 帧标尺 + 当前帧标记，点击任意帧跳转；
- **导出序列**：把「光照 + 全部光绘」合成并导出为 MP4（后台任务，可取消、可下载）。

> 图层「不透明度」作用于笔刷强度、「辉光扩散」作用于半径，且**预览与导出使用
> 同一套换算**，所以所见即所得。「闪烁频率」与「压感曲线」目前是界面参数，
> 引擎不据此改变渲染结果（界面已标注）。

## 18. 光源星图（灯位空间视图）

把当前灯组画在**俯视棚位图**上，便于检查灯位关系。

- **视图**：星图（射线）/ 拓扑（直角连线）/ 列表；
- **左侧**：按 `光源分组` 归类，支持 全部 / 在线 / 离线 过滤与搜索；
  可折叠分组、整组开关；
- **中央**：地面网格与坐标刻度、被摄体、每盏灯按方向定位并标注名称与强度%，
  连线指向被摄体；可缩放、显示光标坐标；
- **右侧**：选中光源的强度 / 色温 / 色相，空间位置（点光为 X/Y/Z，平行光为方向
  向量），以及 静音（等价于「停用此光源」）、独奏、锁定；
- **底部**：真实派生量（光源数、平均色温、相对强度合计、主光:补光 光比）。

> 光束角/衰减曲线/柔光附件是界面级参数，引擎不据此改变渲染（界面已标注）。
> 引擎无法计算绝对光度，因此不显示功率/照度等实测值。

## 19. 智能拾光（从照片提取灯光方案）

从一张**参考照片**反推出可用的三点布光方案，并一键套用到调光台。

1. 点「选择参考图」挑一张光照氛围好的照片；
2. 软件分析亮度梯度与色温分布，给出 场景类型、环境色温 与识别到的光源；
3. 每个光源都有 角色（主光 / 辅光 / 轮廓光）、色温、相对强度、**可信度**，
   以及一句中文的**推断依据**；
4. 「应用到调光台」把结果写入当前参数，随后可继续微调；
5. 「保存为预设」可存成 CUE 供以后调用。

**可推导的量**：关键光比（主光/辅光强度比）、对比度（亮度动态范围）、
色温一致性（灯光色温的集中程度）、相对强度。

> **诚实说明**：本引擎只做图像启发式推断，**无法计算绝对光度**——
> 照度（lx）、显色指数（CRI）、色偏差（Δuv）、闪烁频率、功率等实验室量
> 一律不报告（界面会原文显示该声明）。

## 20. 三维布光预演

## 22. 调光台（CUE 与通道）

以「灯光控制台」的方式管理**多套光照方案**与**每个光源通道**。

- **CUE 预设**：把当前光照存成命名方案（可设 0~30 秒淡变时长）；
  点击 CUE 行即「载入」，把该方案套用到当前参数；可删除、可覆盖同名方案。
- **淡变（GO）**：载入时按该 CUE 的淡变时长**交叉淡化**——
  软件渲染目标画面后，用两张位图叠化过渡（**不会**为动画逐帧重复渲染，
  因此 1~2 秒淡变也是平滑的，且不占算力）；淡变进度在「当前 CUE」处显示。
- **通道条**：每个光源一条，含 通道号、名称、角色（主光/补光/轮廓…）、强度推子；
  **S（独奏）** 只保留该光源、**M（静音）** 等价于「停用此光源」（写入引擎的
  `visible` 字段，真实生效）；另有 **主控 MASTER** 按比例缩放全部强度。
- **灯位图**：俯视图显示被摄体与每盏灯的位置/方向（点光用位置，平行光按方向落在环上），
  可缩放、显示光标坐标。
- **AI 自动打光**：在同一屏内输入文字即可生成光照节点并应用（见第 12 节）。
- **参考图迁移**：可在此屏直接导入参考图做保守偏移，并可撤销。

> 底部会明确标注：强度/色温为引擎相对标度；**照度 lx、CRI、Δuv、DMX、灯具温度
> 本引擎无法计算，因此不显示**。

## 23. 光影指挥屏（灯位与遥测）

面向「一屏总览当前灯组」的视图，只呈现**引擎真实能算出的量**。

- **灯具阵列**（左）：搜索 + 按分组筛选，每行显示 名称、通道、强度% 与强度条、
  色温、在线/停用（由 `visible` 驱动）；点击选中并同步右侧。
- **中央三种视图**：
  - **光位**：俯视归一化平面（点光用位置、方向光按方向落在环上）；
  - **照度**：各通道的**相对贡献**（强度 × 半径归一化）——标注为
    「相对照度分布（相对值，非 lx）」；
  - **热力**：相对强度的归一化热力图——同样标注非 lx。
- **实时遥测**（右）：色温、相对强度、半径、以及由方向向量实测的
  **方位角 / 仰角**（真实三角计算）、该光源的**相对占比**；可锁定以防误改。
- **事件日志**：记录你**本人在本会话中的操作**（如「已应用 CUE」「修改色温」），
  不预置任何虚构条目。
- **CUE 时间轴**：把已保存的 CUE 按淡变时长画成时间条，点击即套用。
- **光比（主光:补光）**：由当前灯组强度实算。

> 本屏明确声明：**照度(lx)、CRI、Δuv、频闪、灯具温度等本引擎无法计算，因此不显示**。
> 因此设计稿中的 DMX Universe、热保护、灯具功率等专业量未予呈现。

## 24. 命令行工具

`hls_cli.py`（打包后为 `hls_cli.exe`）可在脚本或外部宿主中批量渲染图片：

```bash
python hls_cli.py [选项] 输入图 输出图
```

| 选项 | 默认 | 说明 |
|---|---|---|
| `--preset` | `标准棚拍` | 五种预设名之一 |
| `--shadow` | `soft` | `soft`（柔化半影）/ `hard`（硬朗赛璐珞） |
| `--lighting` | `linear` | `linear`（快速预览）/ `hq`（高质量物理阴影） |
| `--ambient` | 预设值 | 环境光强度 0~2 |
| `--exposure` | 预设值 | 整体曝光 0.2~2.5 |
| `--preview-only` | 关 | 仅预览模式，跳过全部 AI 后端，完全离线 |
| `--backend` | 自动 | 强制指定：`builtin` / `local` / `cloud` / `simulate` |

```bash
# 例：高质量物理阴影 + 逆光黄昏
python hls_cli.py --preset 逆光黄昏 --lighting hq in.png out.png
```

## 25. 常见问题

**Q：预览和高质量结果差别大吗？**
快速预览**不做**物理阴影投射，只有高质量模式才有互斥遮挡与半影。
出图请务必切到「高质量（物理阴影）」。

**Q：状态栏显示「仅预览（灰度模拟）」怎么办？**
说明深度来自保底降级。处理：① 设置中下载内置模型；或 ② 启动自建服务并
在设置中启用；或 ③ 启用云端 API。

**Q：为什么是「新文件」而不是覆盖原图？**
这是设计约束：输出永远是与原图同尺寸的新文件，原图不受影响，
便于反复比较不同光照方案。

**Q：云端密钥安全吗？**
密钥保存在本机 `~/.horizon_light_studio/config.json`，仅在使用云端后端时出网，
且云端超时会自动降级，不影响本地功能。

**Q：切换「阴影锐度」会改变高光吗？**
不会。阴影锐度只影响阴影边缘；高光锐度是固定的，避免开关连带改变材质观感。

**Q：「删除此光源」没反应？**
只剩一个光源时会被拒绝（至少保留一个），软件会弹出提示。

**Q：参数调到一半想全部还原？**
点光源面板上方的「↺ 重置全部参数」。

**Q：视频处理很慢怎么办？**
先用「关键帧分析传播」模式（默认）并减少关键帧数量，出片前再决定是否需要
逐帧分析。另外先用「快速预览」调参、确认后再切「高质量物理阴影」。
1080p 30fps 10 秒约 97 秒（关键帧模式）。

**Q：视频输出没有声音？**
正常情况下原音轨会原样保留（音频直通）。若源文件音轨编码特殊，
可先用其他工具转封装一次源文件再处理。

**Q：处理视频时能取消吗？**
可以。取消后会中止并删除半成品文件，不会留下损坏的视频。

**Q：需要自己安装 ffmpeg 吗？**
不需要。依赖 `imageio-ffmpeg` 提供的随包静态 ffmpeg，
`pip install -r requirements.txt` 已包含；也可用环境变量 `HLS_FFMPEG`
指定自己的 ffmpeg。

**Q：AI 自动打光需要联网吗？**
不需要。文字 → 光照节点的解析在本地离线完成（第 12.2 节的规则表）。
只有在设置里启用云端并填了密钥时，才会额外交给大模型做更细解析，
且失败会自动回落到离线结果。

**Q：安装插件安全吗？**
安全。插件是**纯 JSON 数据**，软件只解析、**从不执行插件代码**；
而且每个插件都能单独停用，状态保存在本地。

**Q：换了界面主题会影响出图效果吗？**
不会。主题只改变界面配色（第 15 节），与渲染参数和输出结果完全无关。

**Q：数据目录换了新名字，我原来的模型和缓存还在吗？**
在。软件首次启动会自动把旧品牌目录 `~/.gacha_light_studio` 迁移到
`~/.horizon_light_studio`，已下载的深度模型与 AI 缓存都会保留。

**Q：为什么不用先选图片还是视频模式？**
软件按文件内容自动识别（第 16 节），拖进来即可；图片与视频共用同一套
光照参数与预设。

## 26. 性能参考

实测环境：Intel i7-9750H（6 核 12 线程），CPU 推理。

**图片**

| 分辨率 | 快速预览（线性叠加） | 高质量（物理阴影） | 指标上限 |
|---|---|---|---|
| 512px | < 0.5s | ≈ 1s | — |
| **1024px** | **≈ 0.2s** | **≈ 2.2s** | **≤ 15s / ≤ 60s** |

**视频（关键帧传播模式）**

| 视频 | 帧数 | 实测 | 指标上限 |
|---|---|---|---|
| 320×240 · 15fps · 2s | 30 | ≈ 3.4s | — |
| **1920×1080 · 30fps · 10s** | **300** | **≈ 96.7s** | **≤ 5 分钟** |
| 逐帧分析模式 | — | 随帧数线性增加 | — |

> 质量模式下光照在 `lighting_size`（默认 1024px）上计算后上采样，
> 因此 4096px 图片、1080p 视频的耗时与 1024px 接近，而输出仍为原始尺寸。
> 视频全片处理时内存平稳（1080p 约 +122MB）。
